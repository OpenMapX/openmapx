# TfL Unified API fixtures

These are not recordings. Every TfL request needs an app key, and the
feature-freeze rules forbid live calls during development, so the files follow
the field names and types of the Unified API response models published at
https://api-portal.tfl.gov.uk (`Prediction`, `PredictionTiming`, `StopPoint`
and `StopPointsResponse`). Values are representative London Underground data
written by hand on 2026-11-10. They contain no app key and no personal data.

Replace them with scrubbed recordings when a keyed capture is permitted.
