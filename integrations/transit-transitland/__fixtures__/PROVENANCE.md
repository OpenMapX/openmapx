# Transitland REST fixtures

Example responses published in the Transitland REST API documentation, retrieved
2026-11-10. No API key was used and none appears in the responses.

- `departures.json`: https://www.transit.land/documentation/rest-api/departures
  (BART at Lake Merritt). The stop's nested `parent` was trimmed to its
  identifiers; departures are unchanged.
- `stops.json`: https://www.transit.land/documentation/rest-api/stops (TriMet),
  unchanged.

The underlying GTFS data belongs to the named agencies and is distributed
through Transitland under its terms of service.
