# Aachen photo registration fixture

Photo `813947a9-77f7-4031-8f51-939b2aa6e295`, taken 8 August 2024 by Bastian Greshake Tzovaras. Source: [Panoramax](https://panoramax.xyz/#focus=pic&pic=813947a9-77f7-4031-8f51-939b2aa6e295). Image licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

`aachen-two-lane.rgba.gz` is a 1024 × 512 RGBA derivative resized by Chrome canvas of the source panorama, compressed with gzip for a decoder-independent regression. The derivative retains the same license. The JSON contains source metadata and a short section of the Aachen–Orsoy route geometry. This is a camera-registration fixture with two visible lanes; it does not override photo eligibility or supply lane guidance for this junction.
