# Two-lane photo registration fixture

Photo `813947a9-77f7-4031-8f51-939b2aa6e295`, taken 8 August 2024 by Bastian Greshake Tzovaras. Source: [Panoramax](https://panoramax.xyz/#focus=pic&pic=813947a9-77f7-4031-8f51-939b2aa6e295). Image licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

The compressed RGBA fixture is a 1024 × 512 derivative resized by Chrome canvas of the source panorama, compressed with gzip for a decoder-independent regression. The derivative retains the same license. The JSON contains source metadata and a short road-geometry segment used for camera registration. This fixture has two visible lanes; it does not override photo eligibility or supply lane guidance for this junction.
