## Decision and source boundary

A fresh explicit Update is promised its own checked pull, but R3's ordinary capture cannot own B against cache E; Apply similarly lacks the original candidate/owner. Never reuse/renew/reseal the expired candidate or its parent/grants. This is a historical read-only provenance problem, not authority continuation.

Install one authenticated alternative source in the LITERAL production owned-services resolver, for data-manager ONLY. Its unchanged ordinary cache-image equality remains the default. If that cannot establish DM provenance, a fixed reader of existing actual successful staged-pull records may establish the SAME OLD container's provenance. All other services and all no-proof cases retain Task01.1's exact ordinary checks. This is an explicit narrow amendment to R3's original-candidate-only restriction and Task01.1's current-cache-only source, not a claim that those texts already allow it. Ownership source is separate from action permission: current enabled/protected policy, normal fresh admission, non-recreate Start and mandatory DM maintenance recreate/decision gates remain unchanged.

The authenticated source also permits the currently stopped SAME OLD DM container to be observed as stopped; it does not report readiness. Existing permitted fixed --no-recreate DM Start can then use this proven identity and its OWN fresh policy/admission. No helper is issued after a new pull or while a maintenance root is held. Existing logs/stop permissions are neither expanded nor inferred from ownership alone. Guarded Apply still needs actual running/readiness and its own candidate/root/decision/final; NEW Update still requires its OWN successful checked pull even if downloads are cached. Missing/unknown prior containment never licenses fresh effects.

Reject alternatives: a permanent failed-retry/host-only repair contract violates authorized remote instance management for this normal TTL outcome; accepting arbitrary old tag images weakens ownership; retaining expired MAC as live authority violates TTL; another permanent ownership store is unnecessary because signed normal admissions already contain actual bounded baseline observations.
