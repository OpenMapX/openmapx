Gate derivation must distinguish actual publishing preparation from a nonpublishing lifecycle leaf, not indiscriminately reject every service.start and deadlock the stopped-DM remedy.

This deliberately specializes prior statements that all unrelated ordinary configuration can proceed immediately. It does NOT change the staged source's cfg1/FD/identity verification.
