# 0.1.0-alpha.1 preparation

The committed product-release record selects this version as the first named
prerelease candidate. This preparation page is not publication evidence; verify
the actual GitHub release and bound readiness assets before treating it as
released. OpenMapX remains experimental, without a stable-support commitment or
promised release cadence.

## Compatibility and limitations

The product consists of seven images selected by one manifest, currently targeting `linux/amd64`. Extension protocol compatibility is `1.0`. npm package versions and mobile store versions are separate from the product version; this page does not establish native mobile or ARM acceptance.

## Installation and upgrade

The release workflow must first stage an exact candidate. Before publication, rehearse a clean installation and an upgrade from the actual prebaseline deployment using that candidate's digest-pinned manifest. Record the source deployment and migration results in the bound readiness evidence. No published prior product version is assumed.

Select `preview` only after confirming that a named prerelease has been
published. An absent preview fails without falling back to development images.
Use explicit `main` for development or an exact candidate digest for an
authorized rehearsal. Follow the [product release procedure](../developer/product-releases.md)
for the candidate, rehearsal and approval steps.

Update the operations agent and helper from the host when the maintenance screen requests it. Image rollback does not undo database migrations. Restore/recovery instructions must describe the actual tested procedure and its limits; a passing source test is not an upgrade or recovery rehearsal.

## Publication readiness

No runtime, installation, upgrade or recovery acceptance is claimed here. The owner must review the exact candidate, known limitations, real rehearsal evidence and immutable-release settings before approving publication.
