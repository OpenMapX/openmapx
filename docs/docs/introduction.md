# OpenMapX

OpenMapX is a self-hosted platform for maps, search, navigation, and public
transit, assembled entirely from open data and open-source services. It gives
you a fast, modern map application — place search, directions, transit routing,
layers, and street-level imagery — that you run on your own infrastructure.

This documentation is a work in progress. It will cover:

- **Overview** — what OpenMapX is, how the pieces fit together, and how to get started.
- **Install** — running the stack with Docker Compose and configuring it for your region.
- **Features** — the user-facing capabilities, from search and routing to transit and layers.
- **Administration** — operating a deployment: services, data, and upgrades.
- **Developer** — the architecture, the integration system, and how to extend OpenMapX.
- **Guides** — focused how-tos for common tasks.

:::note

OpenMapX is under active development. Until these pages are complete, the
[project wiki](https://github.com/OpenMapX/openmapx/wiki) remains a useful
reference — though some of it is ahead of or behind the current code.

:::
