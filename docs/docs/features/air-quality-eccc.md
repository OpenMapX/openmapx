# ECCC nearby-community evidence

OpenMapX can include the nearest ECCC named-community observation and forecast
within 100 km as secondary evidence. It shows the official numeric value,
community, distance, current or forecast time, and source attribution.

The record is not treated as the requested point's AQHI. ECCC's machine feed
does not say that the community covers the point or identify conventional AQHI
versus wildfire AQHI+ per record, so OpenMapX shows the standard as
unverified, keeps the value out of the local headline, and labels the
evidence as not establishing coverage for the selected point.
