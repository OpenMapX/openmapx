# Community Integration Development Guide

This guide explains how to create, build, and install community integrations for OpenMapX.

## Overview

A community integration is a self-contained directory with a `manifest.json` and implementation files. It follows the exact same structure as built-in integrations but lives in `custom_integrations/` instead of `integrations/`.

Community integrations can provide:
- **Map overlays** (weather radar, ADS-B tracking, etc.)
- **Data sources** (new POI providers)
- **Transit providers** (additional public transport APIs)
- **Geocoding providers** (alternative search backends)
- **Any combination** of the above

## Directory Structure

```
custom_integrations/
  my-integration/
    manifest.json          # Required: identity, capabilities, config
    index.ts               # Backend: setup function (optional)
    map-layer.tsx           # Frontend: MapLibre layer component (optional)
    legend.tsx              # Frontend: legend/toolbar component (optional)
    panel.tsx               # Frontend: sidebar panel component (optional)
    store.ts               # Frontend: Zustand store (optional)
    strings/
      en.json              # English translations (optional)
      de.json              # German translations (optional)
    package.json           # Dependencies (optional)
    dist/
      index.js             # Pre-built frontend bundle (generated by build)
```

## Manifest Format

The `manifest.json` is the single source of truth for your integration's identity and capabilities.

```jsonc
{
  // Identity (required)
  "id": "weather-radar-rainviewer",
  "name": "Weather Radar (RainViewer)",
  "version": "1.0.0",
  "description": "Live weather radar overlay using RainViewer API",
  "author": "Your Name",
  "license": "MIT",

  // What this integration provides (required)
  "domains": ["map-overlay"],

  // Frontend capabilities (optional)
  "frontend": {
    "mapLayer": true,
    "legend": true,
    "panel": false,
    "layerSelector": {
      "group": "map-details",      // "map-details" | "map-tools" | "map-types"
      "labelKey": "weatherRadar"   // Translation key for the layer selector
    },
    "overlay": {
      "excludes": [],              // Overlay IDs that can't be active simultaneously
      "minZoom": 3
    }
  },

  // Backend capabilities (optional)
  "backend": {
    "routes": true                 // Set true if index.ts registers API routes
  },

  // Configuration schema (optional)
  "configSchema": {
    "type": "object",
    "properties": {
      "enabled": { "type": "boolean", "default": true },
      "apiKey": { "type": "string" }
    }
  },

  // Environment variables this integration reads (optional)
  "envVars": ["RAINVIEWER_API_KEY"],

  // Health check for status page (optional)
  "healthCheck": {
    "type": "http",
    "url": "https://api.rainviewer.com/public/weather-maps.json",
    "category": "Weather"
  },

  // Quality tier
  "quality": "community",         // "built-in" | "community-verified" | "community"

  // Attribution (required for integrations with backend routes)
  "attribution": [
    {
      "name": "RainViewer",
      "url": "https://www.rainviewer.com/",
      "license": "CC BY-NC 4.0",
      "licenseUrl": "https://www.rainviewer.com/terms-of-service.html"
    }
  ],

  // Privacy declaration (required for integrations that call external APIs)
  "privacy": {
    "purpose": "Display live weather radar imagery on the map",
    "dataSent": "Geographic viewport coordinates, timestamp",
    "dataReceived": "Weather radar tile images",
    "providerCountry": "US",
    "providerPrivacyUrl": "https://www.rainviewer.com/privacy-policy.html",
    "personalData": false,
    "cookies": false
  }
}
```

## Backend: `index.ts`

The backend entry point exports a `setup(ctx)` function that receives the platform context:

```typescript
import type { IntegrationContext } from "@openmapx/core";

export function setup(ctx: IntegrationContext): void {
  // Register an API route
  ctx.registerRoute("GET", "/tiles", async (req, res) => {
    const data = await ctx.http.get("https://api.rainviewer.com/...", {
      cache: { ttl: 300 },
    });
    res.send(data);
  });

  // Register a domain provider (e.g., data source, transit, geocoding)
  ctx.registerProvider("map-overlay", {
    id: "weather-radar",
    async fetchData(bbox, zoom) {
      return { type: "raster-tiles", tileUrl: "..." };
    },
  });

  // Register a custom health check
  ctx.registerHealthCheck(async () => {
    const start = Date.now();
    await ctx.http.get("https://api.rainviewer.com/public/weather-maps.json");
    return { status: "up", responseTime: Date.now() - start };
  });

  // Register cleanup on shutdown
  ctx.onShutdown(async () => {
    // Clean up resources
  });
}
```

### IntegrationContext API

| Method | Description |
|--------|-------------|
| `ctx.id` | Integration ID from manifest |
| `ctx.manifest` | Parsed manifest object |
| `ctx.config` | Resolved configuration (env vars + config file) |
| `ctx.http.get(url, options?)` | HTTP client with optional caching |
| `ctx.cache.get(key)` / `ctx.cache.set(key, value, ttl)` | Redis cache (if available) |
| `ctx.log.info(msg)` / `.warn()` / `.error()` | Scoped logger |
| `ctx.registerProvider(domain, provider)` | Register a domain provider |
| `ctx.registerRoute(method, path, handler)` | Register an API route at `/api/integrations/<id>/...` |
| `ctx.registerHealthCheck(fn)` | Register a custom health check |
| `ctx.emit(event, data)` | Emit an event on the integration event bus |
| `ctx.on(event, handler)` | Listen for events (returns unsubscribe fn) |
| `ctx.onShutdown(fn)` | Register a cleanup function |

## Frontend: Components

### Map Layer (`map-layer.tsx`)

A React component that manages MapLibre GL sources and layers:

```tsx
import { useMap } from "@openmapx/core";
import { createOverlayStore, useOverlayExclusion } from "@openmapx/core";
import { useEffect } from "react";

// Create a store for this overlay (auto-registers with overlayId)
const useWeatherStore = createOverlayStore({
  overlayId: "weather-radar",
  extra: { opacity: 0.7 },
  actions: (set) => ({
    setOpacity: (opacity: number) => set({ opacity }),
  }),
});

export default function WeatherRadarLayer() {
  const { mapRef, mapReady } = useMap();
  const layerVisible = useWeatherStore((s) => s.layerVisible);
  useOverlayExclusion("weather-radar");

  useEffect(() => {
    if (!mapReady) return;
    const map = mapRef.current;
    if (!map) return;

    if (layerVisible) {
      // Add raster source + layer
      if (!map.getSource("weather-radar")) {
        map.addSource("weather-radar", {
          type: "raster",
          tiles: ["https://tilecache.rainviewer.com/.../{z}/{x}/{y}/..."],
          tileSize: 256,
        });
        map.addLayer({ id: "weather-radar", type: "raster", source: "weather-radar" });
      }
    } else {
      // Remove layer + source
      if (map.getLayer("weather-radar")) map.removeLayer("weather-radar");
      if (map.getSource("weather-radar")) map.removeSource("weather-radar");
    }
  }, [mapRef, mapReady, layerVisible]);

  return null; // Map layers are side-effect only
}
```

### Legend (`legend.tsx`)

A React component rendered at the bottom of the map when the overlay is active:

```tsx
import { useOverlayExclusion } from "@openmapx/core";

export default function WeatherRadarLegend() {
  // Only render when overlay is active
  const isActive = useOverlayExclusion("weather-radar");
  if (!isActive) return null;

  return (
    <div style={{ background: "white", padding: 8, borderRadius: 4 }}>
      Weather Radar Legend
    </div>
  );
}
```

## Installation

### Using the CLI

```bash
# Install from GitHub
./scripts/integration.sh install github:user/openmapx-weather-radar

# Install from a local directory
./scripts/integration.sh install ../my-integration

# Install a specific version/tag
./scripts/integration.sh install github:user/repo --ref v1.0.0
```

### Manual Installation

1. Clone/copy your integration directory into `custom_integrations/`
2. Run `pnpm install` from the project root (if the integration has dependencies)
3. Build the frontend bundle: `./scripts/integration.sh build <integration-id>`
4. Restart the API server

### Managing Integrations

```bash
# List installed community integrations
./scripts/integration.sh list

# Validate manifest(s)
./scripts/integration.sh validate
./scripts/integration.sh validate weather-radar

# Remove an integration
./scripts/integration.sh remove weather-radar

# Build frontend bundle
./scripts/integration.sh build weather-radar
```

## Building Frontend Bundles

Community integration frontend components are pre-built into ES module bundles that self-register at runtime. The build step is required for any integration with `map-layer.tsx`, `legend.tsx`, or `panel.tsx`.

```bash
./scripts/integration.sh build <integration-id>
```

This uses esbuild to create `dist/index.js` with the following characteristics:
- **Format**: ES module (ESM)
- **Externals**: `react`, `react-dom`, `@openmapx/core`, `maplibre-gl`, `@mui/*` (provided by the platform)
- **Self-registration**: The bundle calls `window.__openmapx_integrations.push()` to register its components

The API server serves these bundles at `/api/integrations/<id>/bundle/index.js`, and the frontend loads them automatically for non-built-in integrations.

## Configuration

Integrations read configuration from environment variables defined in `envVars`:

```bash
# .env or environment
RAINVIEWER_API_KEY=your-key-here
```

For more complex configuration, create `custom_integrations/<id>/config.json`:

```json
{
  "enabled": true,
  "apiKey": "your-key-here",
  "customSetting": "value"
}
```

The integration's `ctx.config` merges defaults from `configSchema` with values from environment variables and `config.json`.

## Quality Tiers

| Tier | Description |
|------|-------------|
| `built-in` | Ships with OpenMapX, maintained by core team |
| `community-verified` | Reviewed and listed in community registry |
| `community` | User-installed, no guarantees |

Set the tier in your `manifest.json` `quality` field. Community integrations should use `"community"`.

## Legal Requirements

Community integrations that make external API calls **must** declare:

1. **`attribution`**: At least one attribution entry with `name`, `url`, and `license`
2. **`privacy`**: Data processing declaration (what data is sent/received, to/from where)

This ensures the OpenMapX privacy policy and terms of service automatically include your integration's data processing activities. The manifest validator will reject integrations with backend routes that lack these declarations.

## Hot Reload

During development, you can trigger a reload of all integrations without restarting the server:

```bash
curl -X POST http://localhost:3001/api/integrations/reload
```

This re-discovers manifests, calls `onShutdown()` on existing integrations, and re-runs `setup()`. Note: Fastify routes registered during the initial load persist; the reload re-executes provider registration and lifecycle hooks.

## Example: Minimal Map Overlay

Here's a complete minimal community integration that adds a WMS tile overlay:

**`custom_integrations/wms-overlay/manifest.json`:**
```json
{
  "id": "wms-overlay",
  "name": "Custom WMS Overlay",
  "version": "1.0.0",
  "description": "A custom WMS tile overlay",
  "author": "You",
  "license": "MIT",
  "domains": ["map-overlay"],
  "frontend": {
    "mapLayer": true,
    "layerSelector": {
      "group": "map-details",
      "labelKey": "wmsOverlay"
    },
    "overlay": { "excludes": [] }
  },
  "quality": "community",
  "attribution": [
    { "name": "Your WMS Provider", "url": "https://example.com", "license": "Open Data" }
  ]
}
```

**`custom_integrations/wms-overlay/map-layer.tsx`:**
```tsx
import { createOverlayStore, useMap, useOverlayExclusion } from "@openmapx/core";
import { useEffect } from "react";

const useStore = createOverlayStore({ overlayId: "wms-overlay", extra: {} });

export default function WmsLayer() {
  const { mapRef, mapReady } = useMap();
  const visible = useStore((s) => s.layerVisible);
  useOverlayExclusion("wms-overlay");

  useEffect(() => {
    if (!mapReady) return;
    const map = mapRef.current;
    if (!map) return;
    if (visible && !map.getSource("wms")) {
      map.addSource("wms", { type: "raster", tiles: ["https://example.com/wms?..."], tileSize: 256 });
      map.addLayer({ id: "wms", type: "raster", source: "wms" });
    }
    if (!visible && map.getLayer("wms")) {
      map.removeLayer("wms");
      map.removeSource("wms");
    }
  }, [mapRef, mapReady, visible]);

  return null;
}
```

Then install and build:
```bash
./scripts/integration.sh build wms-overlay
```
