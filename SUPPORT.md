# Getting help

Use the documentation for setup and feature instructions. For a question about
an existing instance, include its URL and contact its operator when the problem
concerns local configuration, accounts, or stored data.

## Documentation first

Start with the guide for your task:

- [Use the map](https://docs.openmapx.org/overview/using-openmapx/)
- [Troubleshooting and help](https://docs.openmapx.org/overview/troubleshooting/)
- [docs.openmapx.org](https://docs.openmapx.org): full documentation
- [Self-hosting](https://docs.openmapx.org/install/getting-started/)
- [CLI reference](https://docs.openmapx.org/developer/cli-reference/)
- [Architecture](https://docs.openmapx.org/developer/architecture/) and the
  [Integration system](https://docs.openmapx.org/developer/integration-system/)

## Questions, ideas, and discussion

For usage questions ("how do I…?"), configuration help, integration ideas, and
general discussion, use [GitHub Discussions](https://github.com/OpenMapX/openmapx/discussions).

Please don't open an issue for a question — issues track bugs, feature requests, and maintenance work. A bug report can
include observations and open questions; you do not need to prove the cause.

## Bug reports and feature requests

Use the [issue tracker](https://github.com/OpenMapX/openmapx/issues/new/choose)
and pick the appropriate template:

- For a bug report, include reproduction steps and your environment: browser,
  operating system, and relevant services or integrations. Operators can add
  the Node version and deployment details.
- For a feature request, describe the use case. Discuss substantial changes
  before starting implementation.

Before filing, please search existing issues and discussions to avoid
duplicates.

## Security issues

**Do not** report security vulnerabilities in public issues or discussions. See
[SECURITY.md](SECURITY.md) for the private disclosure process.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for development setup, the quality bar, and the pull-request workflow.

## Scope of support

OpenMapX is provided under open-source licenses with **no warranty or
guaranteed support** (see [LICENSING.md](LICENSING.md)). Community help is
best-effort. If you need commercial support or a license for proprietary use,
contact the maintainer.
