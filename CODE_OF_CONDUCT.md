# Code of Conduct

OpenMapX adopts the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).
The full text is published at the link above and is incorporated into this
repository by reference.

In short: everyone participating in OpenMapX — issues, discussions, pull
requests, the wiki, community integrations, chat channels — is expected to
keep interactions respectful, constructive, and on-topic. Disagreements on
technical direction are welcome; personal attacks are not.

## Reporting

If you experience or witness behavior that violates the Code of Conduct,
please contact the maintainer team via the same private channel listed in
[SECURITY.md](SECURITY.md) for security reports. Reports are handled
confidentially.

Maintainers may issue warnings, request edits or deletions, or revoke
participation privileges in response to violations.
