# OpenConditions → OpenMapX contract fixture

`road-conditions-v1.json` is the golden output of OpenConditions' actual
`segmentConditionsToJson` publisher. Its producer test and synthetic input live
under `packages/publishers/src/__tests__/` in OpenConditions. This copy is consumed
by `road-conditions-contract.test.ts` in OpenMapX's normal test suite.

Tests use the fixed instant `2026-09-11T12:00:00.000Z`. They check preservation of
the original parent/child source and licence evidence, forward-only closure
mapping, source exclusions, expiry and ambiguous bindings. No live feed or
cross-repository source import is required.

For an intentional contract change, update both repositories' fixture copies and
run both tests. Compare parsed JSON, since their formatters differ. Keep the
expected fixture independent of the producer during tests so output drift fails.

The fixture is authored synthetic test data. Licence metadata is illustrative
and does not grant rights for any real upstream source.

## `road-restrictions-v1.json`

The normalized vehicle-restriction display contract, version 1. Copied from
OpenConditions, where it is generated from real producer code at the frozen
instant `2026-09-11T12:00:00.000Z`:
`packages/publishers/src/__tests__/fixtures/contracts/road-restrictions-v1.json`.
Both repositories format with the same Biome version and settings, so this copy
is byte-identical to its source. The tests compare parsed JSON either way.

Two consumer suites read it independently. `services/data-manager` parses
`segmentConditions` with the real conditions parser and edge converter and
asserts that every id in `expectedConditionalIds` produces no edge override,
while the unconditional control still does. `integrations/road-conditions`
transports and displays `displayEvents` and feeds them to the real host routing
guard, which must reject them even with adversarial routing claims attached.

The Finnish record is real reviewed source data from Fintraffic under CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/). The four Dutch records are real
reviewed source data from NDW under CC0 1.0
(https://creativecommons.org/publicdomain/zero/1.0/): a height condition, an
emergency-service usage and two lorry classes, each produced by the real DATEX
parser rather than hand-written. The control closure and the adversarial graph
rows are authored test data. Do not edit this file by hand: regenerate it in
OpenConditions, review the diff, and copy it across.

The Dutch records exercise branches the Finnish one does not: event
applicability rather than a permitted maximum, non-numeric class and usage
facts, an Alert-C source direction, and original publisher prose that must be
shown verbatim without being turned into a weight or exemption rule.
